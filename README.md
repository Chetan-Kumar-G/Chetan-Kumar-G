<summary><sub>Classified: for immigration officers only</sub></summary>
<br />

> **Colophon.** This profile is a design project in its own right. The cover, data page, visa stamps, boarding passes, flight log and departures board are all **hand-written SVG**, generated by a small Python toolkit in [`/gen`](gen). Guilloché rosettes are real parametric curves, the rubber-stamp ink is an `feTurbulence` + `feDisplacementMap` filter, the typing terminal is pure SMIL (no JavaScript, since GitHub strips it), and every animation respects `prefers-reduced-motion`.
>
> Change one line in `gen/passes.py` → run `python gen/build.py` → a new boarding pass is issued.
